CJet — the security guard

A LangChain agent with three guard positions: the input is checked before the model runs, the tool arguments are checked before the tool runs, and the model's own answer is checked after it is produced. A check that fires stops the run and returns a blocked answer. ← back to the main UI

What this page is showing

The guard model dropdown picks which model checks for PII. The chat model that answers is separate (…).
The arms are not interchangeable. The same PII prompt scores about 0.84 on the english checkpoint and about 0.50 on the doc head, which was trained on one synthetic contact line rather than on prose. The typed head is worse than useless on PII — it scores the clean text higher. Switch the dropdown and resend to see it.
A jailbreak finding is reported but does not block by default: the measurement behind that is in the README. The secret scanner always blocks, on every arm, because a matched key format is a fact and not a probability.
